## Published releases

Read [GitHub Releases](https://github.com/chitranklabs/ask-widget/releases) for
published versions and release notes. The repository’s
[CHANGELOG.md](https://github.com/chitranklabs/ask-widget/blob/main/CHANGELOG.md)
contains the generated change history.

The library, website and documentation build independently. Use the version in
your installed package when checking API behavior against a release.
