ask-widget provides a floating chat interface, a streaming response adapter and
headless hooks. Use the supplied widget or compose your own interface around
`useChat`, `useSSEStream` and `useSession`.

## Start with a working example

Follow [Getting started](/getting-started) to install the scoped package and
render a demo. Then connect a backend using the [SSE contract](/backend), or
supply a custom response handler from the [API reference](/api).

## Choose your integration

- [Next.js and Vite](/integrations): client boundaries and stylesheet imports.
- [Theming](/theming): light/dark presets and custom colors.
- [Standalone hooks](/hooks): custom UI and browser-local persistence.
- [Troubleshooting](/troubleshooting): missing styles, network failures and history.
