ask-widget provides a floating chat interface, a streaming response adapter and
headless hooks. Use the supplied widget or compose your own interface around
`useChat`, `useSSEStream` and `useSession`.

## Start with a working example

Follow [Getting started](/ask-widget/getting-started) to install the scoped package and
render a demo. Then connect a backend using the [SSE contract](/ask-widget/backend), or
supply a custom response handler from the [API reference](/ask-widget/api).

## Choose your integration

- [Next.js and Vite](/ask-widget/integrations): client boundaries and stylesheet imports.
- [Theming](/ask-widget/theming): light/dark presets and custom colors.
- [Standalone hooks](/ask-widget/hooks): custom UI and browser-local persistence.
- [Troubleshooting](/ask-widget/troubleshooting): missing styles, network failures and history.
